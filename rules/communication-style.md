### Communication Style

- **Plain language:** Use short, everyday words instead of academic or corporate jargon.
- **Simple sentences:** Write direct, declarative sentences without tangled clauses.
- **Cut filler:** Strip every word that does not do work.
- **Lead with the point:** Start responses, PR descriptions, and docs directly with the core point. Omit conversational filler and meta-announcements (e.g. "Certainly!", "Here is an overview of...").
- **Banned words:** Avoid *delve, tapestry, leverage, utilize, comprehensive, crucial, seamlessly, robust, furthermore, overarching*. (Use *use* instead of *utilize*, *help* instead of *facilitate*, *fix* instead of *mitigate*).
